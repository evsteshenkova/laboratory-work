# Students Risk BBKemSU

## Как запустить

1. Создай файл `.env` (рядом с этим README):

2. Запусти все сервисы:
```bash
docker-compose up --build -d
```

3. Проверь:

    Фронтенд: http://localhost:3000

    MLflow: http://localhost:5001

Сервисы общаются:

Фронтенд - Бэкенд (данные студентов)

Бэкенд - MLflow (предположительно☺)

Трейнер - БД (читает данные)

Трейнер - MLflow (предположительно☺)
